# Chapter 3 — Table 3.1

[table_3_1.ipynb](table_3_1.ipynb) computes sampling costs for H₂, HF, and CO₂.

## Run

Open the notebook with a Python kernel that has the [required packages](../README.md#requirements). Keep one molecule's `geo` assignment active, restart the kernel, and run all cells. The final cell prints both sampling totals.

In the tested environment, the conventional CO₂ result rounds to `1.22e14`, compared with `1.21e14` in the thesis. The other results agree at the table's displayed precision.

## Related paper

Xuanqiang Zhao, Benchi Zhao, Zihan Xia, and Xin Wang. [*Information recoverability of noisy quantum states*](https://doi.org/10.22331/q-2023-04-13-978) (2023).
